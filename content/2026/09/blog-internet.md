블로그를 만들고 나서 며칠간 사용하려고 하다 보니까, 블로그를 인터넷에서 수정하고 싶은 생각이
들었습니다. 로컬 환경에서만 수정하는 것은 편리하지만, 인터넷을 통해서도 접근할 수 있으면 더 좋겠다는
생각이 들었습니다. 물론 OpenSSH를 통해서 어디에서나 컴퓨터에 로그인해 컴퓨터를 사용할 수 있도록
설정해두었지만, 직접 코드를 수정하는 것보다는 블로그를 인터넷에서 바로 수정할 수 있는 방법이 더
편리할 것 같다는 생각이 듭니다.

하지만 인터넷으로 수정하기 위해서는 파일 시스템을 수정하는 API를 만들어야 할 것입니다... 이건 너무
귀찮기 때문에, GitHub Actions에서 새로운 글을 작성하는 스크립트를 만들거나 하는 것이 좋다는 생각이
듭니다.
